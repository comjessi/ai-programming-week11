# 12주차 성적 데이터 분석

## 데이터

출처는 「AI 협업 프로그래밍」 12주차 실습 배포 자료다. 본 데이터 `scores_2026.csv`는 UTF-8, 114행 5열이다. `scores_2026_cp949.csv`는 같은 데이터를 CP949로 저장한 파일이고, `mini.csv`는 손계산 대조용 10행 데이터다. CSV가 없는 경우 수업 배포본을 이 폴더에 복사한 뒤 실행한다.

| 열 | 설명 |
| --- | --- |
| 학번 | 학생 식별 번호 |
| 이름 | 학생 이름 |
| 반 | 1반 또는 2반 |
| 과목 | 수학, 영어, 프로그래밍 |
| 점수 | 해당 과목 점수, 0~100점 |

점수가 비어 있는 행은 평균과 중앙값에 임의로 채운 점수가 반영되는 것을 피하기 위해 제외했다. 완전히 같은 행은 하나만 남긴 후 반·과목의 앞뒤 공백을 제거했다. 이후 0~100 범위 밖의 점수를 제외했다.

## 실행

저장소 루트에서 실행한다.

```bash
python3 -m pip install pandas pytest
python3 week12/analysis.py
python3 -m pytest -q week12
```
